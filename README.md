# 🔧 Painel Admin - Felix Delivery

Sistema de gerenciamento administrativo para o Felix Delivery, desenvolvido com HTML, CSS e JavaScript puro.

![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-yellow)
![Version](https://img.shields.io/badge/Versão-1.0-blue)

## 📋 Sobre o Projeto

Painel administrativo completo para delivery, com interface moderna e responsiva. Permite gerenciar pedidos em tempo real, produtos, configurações da loja e muito mais.

### ✨ Funcionalidades

- **Login Administrativo** (padrão: admin / 123)
- **Dashboard** com total de pedidos e valor faturado
- **Kanban de Pedidos** (Pendente, Em preparo, Saiu para entrega, Entregue, Cancelado)
- **Gestão de Produtos** (cadastrar, editar e excluir)
- **Configurações da Loja** (nome, cores, delivery, WhatsApp, etc.)
- **Visualização de Pedidos Cancelados**
- **Atualização em tempo real** dos status dos pedidos
- Design moderno e responsivo (funciona bem no celular)
